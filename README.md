# Simplicity - Enterprise Consulting Website

## Overview

A modern, responsive business consulting website built with **HTML, CSS & JavaScript**. The project is designed for enterprise consulting firms to showcase their solutions, build trust with clients, and generate leads through an elegant, professional interface.

## Live Demo / Installation

```bash
git clone https://github.com/anik558363/Simplicity
cd Simplicity
```

Then simply open `index.html` in your browser — no build tools required.

## Features

- **Responsive Design** — Optimized for mobile, tablet, and desktop views.
- **Hero Section** — Bold introduction with call-to-action.
- **What We Offer** — Highlighting core service offerings with visual cards.
- **About Section** — Company introduction with feature highlights.
- **Trusted By / Certifications** — Brand & framework logo showcase.
- **Why Choose Us** — Value proposition section with supporting imagery.
- **Our Work Process** — Step-by-step timeline showing how solutions are delivered.
- **Services Grid** — Clean card-based layout for all business solutions.
- **Client Testimonials** — SwiperJS-powered testimonial carousel with ratings.
- **Contact Section** — Contact form with embedded Google Map.
- **Footer** — Quick links, legal links, contact info & newsletter subscription.

## Technologies Used

- **[HTML5](https://html.com/)** — Structure and layout of the website.
- **[CSS3](https://www.w3.org/Style/CSS/)** — Styling with Flexbox and CSS Grid for responsive design.
- **[JavaScript](https://www.javascript.com/)** — Interactive elements and dynamic content.
- **[Bootstrap 5](https://getbootstrap.com/)** — Responsive grid system and components.
- **[SwiperJS](https://swiperjs.com/element/)** — Touch-friendly testimonial carousel.
- **[Font Awesome](https://fontawesome.com/)** — Icon library.
- **Google Fonts** — Montserrat, Cormorant Garamond, Inter, Urbanist.
- **Google Maps Embed** — Location display in the contact section.
